GETTING STARTED & COMMANDS

使い方・コマンド一覧

最初の会議から、要約と記録の整理まで。

はじめ方コマンド一覧名前・役職メモ字幕の画面共有困ったとき

まずはこの4ステップ

Botをサーバーに追加し、参加者に文字起こし・保存・共有範囲を説明してから開始してください。Botを動かすPCとローカルモデルの起動が必要です。

  1. VCに参加して開始

    通常のVCに入り、同じサーバーのテキストチャンネルで /meeting start title:定例会議 を実行します。BotがVCに参加します。

  2. 字幕を見る

    /meeting screen のURLをBot稼働PCで開きます。既定では発言ごとのチャット投稿は行いません。

  3. 必要に応じて一時停止・再開

    /meeting pause で一時停止、/meeting resume で再開します。英訳は /meeting translation enabled:true で有効にできます。

  4. 終了して要約

    /meeting stop で保存して退出。続いて /meeting summary を実行すると要約カードとHTMLが出ます。/meeting gantt ではタスクの日程も確認できます。

コマンド一覧

Discordで / を入力してコマンドを選びます。下の例の名前・値は、自分の会議に合わせて変更してください。「指定できる項目」を開くと必須項目や選択肢を確認できます。

/help使い方・コマンド一覧のリンクを本人だけに表示

要約・ガント・エクスポートには id:会議ID も指定できます。省略時は実行したチャンネルの進行中または最新の会議です。会議IDは開始・終了の通知や /meeting history で確認できます。

名前・役職メモを使い分ける

Discordのロールを付与する機能ではなく、文字起こしに添える表示名・メモです。

継続メモ：変更・削除まで引き継ぐ

/speaker set user:@山田 scope:persistent name:山田部長 note:部長

scope は「継続するメモ（部長など）」を選びます。

会議メモ：今回だけ適用

/speaker set user:@山田 scope:session note:司会

scope は「この会議だけ（司会など）」を選びます。字幕には「部長 / 司会」のように両方が表示されます。同じ保存範囲への再設定はそのメモの更新になります。

変更は以後の発言に適用されます。過去の発言は書き換わりません。会議限定メモも元の議事録には残ります。自分の設定は本人が、他の人の設定は会議開始者またはサーバー管理権限を持つ人が変更できます。

字幕を画面共有する

  1. /meeting screen のURLをBot稼働PCのブラウザで開きます。
  2. 「画面共有モード」で字幕を大きくし、文字サイズを調整します。
  3. Discordの画面共有で、そのブラウザウィンドウを選びます。

字幕URLはBot稼働PC専用です。他のPCの参加者には共有映像を見せてください。Bot再起動後は /meeting screen でURLを取り直します。チャットにも字幕が必要なら /meeting output mode:chat、画面だけに戻す場合は mode:screen を選びます。

困ったとき

Botがサーバーのメンバーにいない

「マイアプリに追加」だけではVCへ参加できません。Botをサーバーに追加するから、管理権限のある追加先を選んで認可してください。

コマンドが見つからない・応答しない

Botがサーバーに参加していること、稼働PCでBotが起動していること、チャンネルでアプリコマンドが許可されていることを確認してください。追加・登録直後はDiscord画面を開き直してから再確認します。

要約を実行できない

/meeting pause または /meeting stop を先に実行してください。会議操作・要約は開始者またはサーバー管理権限を持つ人が行えます。ローカルの要約モデルが起動している必要があります。

一時停止後も字幕が追加された

一時停止前に確定した音声区間は処理を完了させます。未確定の音声は破棄し、停止中の新しい音声は追加しません。

ガントに棒が表示されない

開始日・終了日の両方が分かるタスクを棒で表示します。不明な日付は推測せず「日付未定」として残します。

音声認識・英訳・要約には誤りが生じることがあります。重要な担当や日程は発言録と照合してください。会議データには現状、自動削除期限がありません。詳細はプライバシーポリシーをご確認ください。
